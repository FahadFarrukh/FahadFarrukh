### Selected work

<details>
<summary><strong>01 &nbsp; VisIA · Language understanding & neuro-symbolic AI</strong></summary>

`Multi-agent systems` `SQL RAG` `CrewAI` `LangChain` `Flask`

`Databricks` `PySpark` `Delta Lake` `ADLS Gen2` `Power BI`
